# 💗 نمنم ♥ هدية الحب

موقع رومانسية تفاعلي (ملف HTML واحد) — هدية عيد حبيبة لـ **نمنم**.

## المحتوى

- ✨ **المرحلة الأولى:** صندوق هدية ثلاثي الأبعاد ينفتح بقلوب طايرة، وتظهر رسالة باللهجة العراقية.
- 💭 **المرحلة الثانية:** ثلاث بطاقات زجاجية تنقلب بسلاسة، كل بطاقة فيها رسالة حب باللهجة.
- 🌹 **المرحلة الثالثة:** صندوق سحري ينفجر بالورد، ثم وردة ذهبية متوهجة تفتح الرسالة الكبرى.

## المميزات

- مطر بتلات الورد الأحمر عبر `Canvas` — بتلات مرسومة مسبقاً (sprites) لأداء سلس على الهاتف.
- موسيقى رومانسية مولّدة بالكامل عبر `Web Audio API` (بدون أي ملفات صوت).
- شريط تقدّم للمراحل الثلاث، وشاشة ختامية قابلة لإعادة التشغيل.
- تصميم **موجّه للهاتف أولاً**: `RTL`، `viewport-fit=cover`، مساحات آمنة لأجهزة iPhone، أزرار كبيرة سهلة اللمس.
- بدون أي مكتبات تحتاج تنصيب — Tailwind CSS وخطوط Google عبر CDN فقط.
